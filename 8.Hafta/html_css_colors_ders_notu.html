HTML ve CSS'te Renk Kullanımı

Color • HEX • RGB • RGBA • HSL • Opacity

1. Renkler neden kullanılır?

CSS renkleri; yazıların, arka planların ve kenarlıkların görünümünü belirler. 

p {
  color: blue;                 /* Yazı rengi */
  background-color: lightgray; /* Arka plan rengi */
  border: 2px solid red;       /* Kenarlık rengi */
}

color yazı rengini, background-color arka plan rengini belirler.

2. Renk adları (Color Names)

CSS'te red, blue, tomato, orange, purple ve lightgray gibi hazır renk adları kullanılabilir.

red
blue
tomato
lightgray

Kolaydır ancak her renk tonu için bir isim bulunmaz.

3. HEX renk kodu

HEX renkleri onaltılık sayı sistemiyle ifade eder. Başında # bulunur. Genel biçimi #RRGGBB şeklindedir.

  • RR: Kırmızı (Red)
  • GG: Yeşil (Green)
  • BB: Mavi (Blue)
h1 { color: #ff0000; } /* Kırmızı */
body { background-color: #ffffff; } /* Beyaz */
p { color: #000000; } /* Siyah */
#FF0000
#00AA00
#0000FF
#FFFF00

4. RGB renk modeli

RGB; Red (kırmızı), Green (yeşil) ve Blue (mavi) kelimelerinin baş harflerinden oluşur. Her kanal 0 ile 255 arasında değer alır.

Yazım biçimi: rgb(red, green, blue)

  • rgb(255, 0, 0) = kırmızı
  • rgb(0, 255, 0) = yeşil
  • rgb(0, 0, 255) = mavi
  • rgb(0, 0, 0) = siyah
  • rgb(255, 255, 255) = beyaz
.ornek { color: rgb(255, 0, 0); }
255, 0, 0
0, 255, 0
0, 0, 255
255,255,255

5. RGBA: Şeffaflık eklemek

RGBA modeline dördüncü bir değer ekler: Alpha. Alpha 0 ile 1 arasında saydamlık düzeyidir. 0 tamamen şeffaf, 0.5 yarı saydam, 1 tamamen opaktır. 

.kutu { background-color: rgba(255, 0, 0, 0.5); }
Bu kırmızı arka plan %50 saydamdır.

6. HSL ve HSLA

HSL rengi üç bileşenle tanımlar:

  • Hue (Ton): Renk açısı, 0–360 derece.
  • Saturation (Doygunluk): Rengin canlılığı, yüzde olarak.
  • Lightness (Açıklık): Açıklık/koyuluk düzeyi, yüzde olarak. 
h2 { color: hsl(0, 100%, 50%); }
.kutu { background-color: hsla(210, 100%, 50%, 0.5); }

Yaklaşık olarak 0° kırmızı, 120° yeşil, 240° mavi tonunu ifade eder.

7. Opacity özelliği

opacity, HTML elemanının tamamının saydamlık düzeyini ayarlar. Değer 0 ile 1 arasındadır. 

.resim { opacity: 0.5; }
opacity: 1
opacity: 0.5
opacity: 0.2
Önemli fark: RGBA ile yalnızca belirtilen renk saydamlaşır. Opacity kullanıldığında elemanın yazısı ve diğer içerikleri de saydamlaşır.

8. Aynı rengin farklı yazımları

Aşağıdaki ifadeler yaklaşık olarak aynı mercan tonunu gösterir:

  • Color name: tomato
  • HEX: #ff6347
  • RGB: rgb(255, 99, 71)
  • RGBA: rgba(255, 99, 71, 0.5) (yarı saydam)
  • HSL: hsl(9, 100%, 64%)

9. Öğrenci alıştırmaları

  1. Bir başlığın rengini tomato yapın.
  2. Bir paragrafın rengini HEX ile #203864 yapın.
  3. Bir kutunun arka planını rgb(255, 220, 120) yapın.
  4. Bir butona rgba(0, 100, 200, 0.6) arka plan rengi verin.
  5. Bir görselin opacity değerini 0.5 yapın.
  6. Aynı rengi color name, HEX ve RGB biçiminde yazın.
